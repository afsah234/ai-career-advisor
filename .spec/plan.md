# Project Plan

## Overview
This project is an AI-powered modern website built using Next.js and Spec-Kit structure. The goal is to create a scalable, clean, and responsive UI with modular components.

## Phase 1: Project Setup
- Initialize Next.js project
- Setup Tailwind CSS
- Create folder structure
- Configure Spec-Kit (.spec folder)

## Phase 2: Core Layout
- Build main layout.tsx
- Create Navbar component
- Setup Footer component
- Add responsive container system

## Phase 3: Pages Development
- Home Page
- About Page 
- Quiz 
- Result
- Contact Page


## Phase 4: Components
- Navbar/Footer
- Chat widget (AI integration)

## Phase 5: AI Integration
- Connect Groq / OpenAI / RAG / CLAUDE
- Build chat API route
- Handle errors & fallback responses

## Phase 6: Styling & UX
- Responsive design (mobile-first)
- Animations and hover effects

## Phase 7: Testing & Fixes
- Bug fixing
- UI responsiveness check
- API testing

## Phase 8: Deployment
- Deploy on Vercel
- Environment variables setup
- Final production optimization
