# Project Constitution

## Project Name
AI Career Advisor

## Goal
To build a modern, responsive, and AI-assisted website using Spec-Kit and Claude Code.

## Tech Stack
- Tech Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- AI Layer: RAG, Claude AI, Groq
- UI Components: Lucide React
- Deployment: Vercel

## Rules
- Clean code structure
- Mobile responsive design
- Reusable components
- No hardcoded data (prefer JSON or API-based data)

## Scope
- Navbar
- Homepage
- Content pages (About,Quiz,Result,Contact)
- Chat widget (AI powered)

## Out of Scope
- Future Enhancements (Out of Scope for Now)
- Payment system integration (for premium features in future)
- Admin dashboard for managing users and analytics
- User authentication (login/signup system)
- Personalized AI career roadmap based on user progress
- Resume analysis and improvement suggestions using AI
- Job recommendation system based on user skills
- AI chatbot with advanced memory and context awareness
- Database integration for saving user quiz history and results
- Career trend analytics using real-world job market data
- Multi-language support for wider accessibility
- Dark mode UI for better user experience
- Mobile app version (React Native / PWA)
